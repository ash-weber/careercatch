## 🎯 Documentation Structure for Each Section

Each dedicated document strictly adheres to a uniform structure:

1. **Section Overview & Identity**: File path, anchor ID, semantic HTML tag, and visual layout hierarchy.
2. **Core Purpose & Business Goals**: Why this section exists, target psychological milestones, and key conversion metrics.
3. **Component Rationale & Comparative Justification**: Why this specific layout and UI pattern was chosen over conventional alternatives.
4. **Detailed Technical Architecture**: Component props, local state hooks, external library dependencies, and data structures.
5. **Design System & Visual Tokens**: Typography classes, color tokens (Ice Blue, Midnight Navy, Electric Blue, Amber), borders, and spacing.
6. **Micro-Interactions & Animation Choreography**: Scroll-triggered reveals, hover states, GSAP / Motion curves, and spring physics.
7. **Accessibility & Responsive Breakdown**: Semantic landmarks, ARIA attributes, keyboard support, `prefers-reduced-motion` compliance, and viewport breakpoints.
